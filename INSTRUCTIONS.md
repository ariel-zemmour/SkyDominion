# SkyDominion Instructions

This file contains instructions and guidelines for development and gameplay systems in SkyDominion.

## Project Overview
SkyDominion is a high-performance 3D flight simulator built with React, Three.js, and Zustand.

## Core Systems
- **Combat**: Advanced targeting, radar, and missile systems.
- **Flight**: Physics-based flight model with fuel management and afterburners.
- **Environment**: Dynamic weather (rain, storms, fog) and large-scale terrain.
- **Career**: Rank-based progression and mission-based gameplay.
- **Ejection**: Integrated emergency escape system with parachute physics.
